# OnlyPing v0.1.2-alpha.1 · 项目首页与图片导出升级

应用内部版本为 0.1.2，相较 v0.1.1-alpha.1 汇总第二十一至第二十六批更新。此版本仍为未签名的 Windows 桌面预发布测试版。

## 下载与升级

- `OnlyPing_v0.1.2-alpha.1_windows-x64_setup.exe`：Windows x64 安装包。
- `OnlyPing_v0.1.2-alpha.1_windows-x64.zip`：解压后运行 `OnlyPing.exe`，需要 Microsoft Edge WebView2 Runtime；不需要 Node、Rust 或开发服务器。
- `SHA256SUMS.txt`：安装包与独立运行包的 SHA-256 校验值。

支持 Windows 10/11 x64。独立运行包与安装版使用相同应用标识和本地数据目录，不是数据随程序目录移动的便携模式。升级前请备份重要项目 JSON，并退出旧版；避免多个版本同时编辑同一项目。

## 项目首页与默认目录

- 桌面启动展示最近 12 个已保存文件项目，包含缩略图、名称、图片数和路径，点击直接打开；可返回项目首页。
- 新项目 Ctrl+S 直接保存到系统文档下的 `OnlyPing/Projects`，首页可更改默认目录；已有项目继续写回原位置。
- 项目名生成可读 JSON 文件名，重名自动编号；修改标题不会自动重命名文件。
- 文件关联与项目索引由原生 SQLite 保存，可跨重启恢复。打开桌面文件保留项目标识，避免同一项目重复列出；Web 导入仍生成独立项目。
- 项目文件被外部修改或删除时拒绝覆盖；缺失文件提供重新定位提示，恢复存档与历史入口保留。
- 首页缩略图保留打码和遮挡，生成失败回退为图标。

旧版本仅存于本机恢复库的项目不会批量转换成文件：从“本机恢复存档与历史”打开，首次手动保存后加入首页。自动恢复存档与手动 JSON 文件继续分别保存，恢复的工作区可能保守显示待保存，再按 Ctrl+S 确认即可。原生项目文件操作限制为 512 MiB。

## 标注图片导出

- 原始尺寸、按比例缩小或限制最大宽度；标注随图片同步缩放，不放大小图。
- 保留项目连续序号或每张从 1 开始，文件名仍按项目步骤顺序编号。
- 支持 PNG 与 JPEG，JPEG 质量可设置为 1–100，透明区域填白；单张、ZIP 和桌面文件夹均适用。
- 桌面可选择独立图片保存到文件夹：每次新建子目录，逐张暂存并以不覆盖方式提交；取消或失败保留已完成图片并报告数量和位置。
- 记住上次导出设置，支持恢复默认；不保存图片选择或目录授权。
- 结果面板区分桌面保存与浏览器发起下载，展示完成/未完成图片、失败位置，可重新查看最近结果；桌面支持打开已登记的导出目录。
- JPEG 压缩预览支持范围内切换样张、调整质量、适应窗口与 100% 查看，显示实际样张体积。预览与导出共用绘制和编码路径，无额外下载、上传或 AI 请求。

快捷当前页/列表行导出仍使用原始尺寸 PNG；自定义格式、尺寸、序号和保存方式请从“导出标注图片…”设置。每批最多 1000 张，编码图片合计不超过 200 MiB；不是整个项目内存上限，也不是 ZIP 流式写入。

## 验证与已知边界

发布前执行前端/Node 回归、Rust 测试、lint、前端体积检查及正式 release/NSIS 构建。当前回归基线为 137 项前端/Node、20 项 Rust；独立浏览器 23 项导出/预览断言与真实 PNG/JPEG/ZIP 校验通过。

独立 QA 桌面已验证首次 Ctrl+S 无路径对话框直接保存、重启显示最近项目、卡片打开、再次保存写回同一文件，以及首页新建项目首次保存；核对了索引与文件标识。首页浏览器截图为独立样式 fixture，不替代原生 I/O 验收。

自定义目录选择、不可写磁盘/磁盘不足、长路径、大型非空项目完整 UI、导出文件夹/资源管理器完整交互及本版本安装升级仍需手验，详见 DESKTOP_ACCEPTANCE.md。没有代码签名、自动更新、WebP 或系统文件关联。

项目文件与索引提交不是跨存储事务；文件已写入但索引失败会提示路径，需保留工作区并检查文件。外部修改检测仍有最终检查到替换间的竞争窗口。取消不能即时打断 Canvas 编码或撤回已开始的磁盘写入。源图仍需完整解码，预览与批量导出会额外占用内存。

# OnlyPing v0.1.4-alpha.1 · 文档排版与实时预览

截图操作指引的文档排版升级，新增图文分栏、多图排版、品牌头部和预览内编辑，同时整理工作台顶栏。此版本为 Windows x64 预发布测试版。

## 下载与使用

- `OnlyPing_v0.1.4-alpha.1_windows-x64_setup.exe`：Windows x64 安装包。
- `OnlyPing_v0.1.4-alpha.1_windows-x64.zip`：解压后运行 `OnlyPing.exe`；需要 Microsoft Edge WebView2 Runtime，不需要 Node、Rust 或开发服务器。
- `SHA256SUMS.txt`：上述两个发布文件的 SHA-256 校验值。

独立运行 ZIP 与安装版共用应用标识和本机数据目录，不是数据随程序目录移动的便携模式。升级前退出旧版，并备份重要项目 JSON；运行中的旧实例可能被单实例机制重新唤起。

## 新增与改进

- 文档支持上文下图、左文右图、左图右文、双列、三列及双图共享说明区。按原顺序连续分行，末行保持列宽；同一行以最高说明区统一留白，所有截图顶部对齐。
- 文档头部支持副标题、背景色/本地背景图、文字颜色、背景显示方式、遮罩、Logo 和 80–600px 最小高度；长标题与说明自动撑开，素材在本机处理并随项目保存。
- 步骤标题支持常规文字、圆点数字加步骤名称、文字加 Badge，装饰编号可调整颜色。
- 导出预览新增可收起的版式侧栏。可直接调整布局、头部、文字与页脚，自动更新预览；生成期间保留上次成功画面并说明状态，修改参与项目保存与撤销。
- 设置中心新增独立“文档排版”分类，布局、头部、文字页脚使用统一行布局，与预览共用控件。
- 简化工作台顶栏：项目首页归入项目菜单，移除重复文件名，保存状态移到左侧标题旁；设置移到快捷键旁，统一主操作按钮高度。

长图、PDF 与预览共用排版管线；Word 使用无边框表格组织图文，背景/Logo 头部与装饰编号使用内嵌图片，正文保持可编辑。纯标注图片导出不添加文档头部与说明。

## 验证与边界

185 项前端/Node 回归通过；TypeScript、全量 ESLint、前端体积预算和 Windows release/NSIS 构建通过。隔离浏览器已检查六种布局、长标题/副标题、编号装饰、多列顶部对齐、存档素材往返、预览内编辑及 Word 文档结构。

当前布局应用于整篇项目，暂不支持手动分组或单个步骤覆盖。Word/WPS 实际打印分页、原生素材选择/保存和大型项目仍需实机确认；隔离浏览器与文档结构检查不代表这些场景已通过。三列长截图会降低阅读尺寸，超高行可能在 PDF 中跨页切分。

本版本没有配置正式更新公钥，不启用自动更新，不包含更新签名或 `latest.json`。请下载安装包手动升级。正式签名包下载、UAC/NSIS 跨版本升级和数据保留验收仍待完成，详见 UPDATES.md 与 DESKTOP_ACCEPTANCE.md。

# OnlyPing

面向截图操作指引的本地工具：整理多张步骤图片、标注操作位置、编写富文本说明，导出单页 PNG、拼接长图、PDF 和 Word。桌面端使用 Tauri 外壳，同时保留 Web 入口。

标注支持标准／强调箭头；矩形和椭圆支持仅边框、边框加填充、仅填充，以及线宽、虚线、独立填充颜色与不透明度，矩形可调圆角。新建和已选标注均从顶部参数栏配置，旧项目保留兼容样式。

标注文字、文字框和说明气泡支持字号、字重、对齐、行距、背景色与不透明度、内边距和圆角；普通文字可切换描边，气泡文字颜色可独立于边框。序号支持实心圆、空心圆、方形及颜色，三位数自动缩小字号；高亮可调不透明度。各工具分别记忆新建默认参数，文字与文字框互相独立，已有标注仍单独编辑。

箭头还支持曲线样式，选中后拖动中间控制点调整弯曲；气泡可拖动尾端指向目标，两者均可重置。绘制矩形、椭圆、放大区域或裁剪时按住 Shift 可约束为正方形／正圆；绘制或调整箭头、直线端点时按住 Shift 可约束为 45° 倍数。新建画笔默认平滑、按帧采样并在结束时简化点；移动放大镜复用现有取样图。

## Windows 桌面端

`npm run desktop:dev` 启动桌面开发；`npm run desktop:build` 构建内嵌前端资源的 Windows 程序与 NSIS 安装包。桌面正式运行不需要启动开发服务器。

当前已接入原生项目打开、导出保存、关闭前保存、Windows 凭据管理器和 SQLite 自动存档。首次启动会迁移同一桌面来源的 IndexedDB，保留原数据；Web 继续使用 IndexedDB。开发前置条件、数据迁移方式及尚未完成的原生交互验收见 [DESKTOP.md](DESKTOP.md)。

桌面端启动首页展示最近 12 个项目，合并项目文件与本机草稿，同一项目不会重复列出。支持按名称或文件路径搜索、固定常用项目、移除和恢复首页记录；列表设置跨重启保留，移除记录不删除文件或恢复存档。新项目按 Ctrl+S 直接保存到默认的系统文档 `OnlyPing/Projects` 目录，可在首页更改；已有项目重启后仍写回原文件。项目文件和恢复存档内容不同时，可选择打开文件、恢复修改或另存独立副本。自动恢复存档和手动项目文件分别保存。

项目文件移动或改名后，可从最近卡片的版本窗口重新定位。只接受相同项目标识的文件，先核对新旧位置及恢复存档，再确认关联；取消或选错文件保留原关联，定位操作不会改写项目文件。

桌面端新增系统托盘：左键恢复主窗口，右键提供打开、设置和退出。关闭窗口首次询问退出或隐藏，可记住选择；最小化到托盘单独设置且默认关闭。隐藏前提交输入并保存本机恢复存档，明确退出仍检查未保存的项目文件。托盘不可用时保留正常退出行为。

工作台顶栏、桌面项目首页和托盘均可打开设置，也支持 Ctrl+,。设置中心包含常规、项目与存储、编辑器、图片导出、AI 与隐私和关于；整合默认项目目录、恢复存档管理与数据目录、工具排序/默认样式/面板布局恢复、图片导出默认值和 AI 配置。应用偏好与项目内容分别保存，桌面持久密钥继续使用 Windows 凭据管理器。浏览器入口隐藏桌面专属操作。桌面端按应用标识限制为单实例，重复启动恢复已有窗口；QA 标识独立。默认记住普通窗口大小、位置与最大化状态，可在常规设置中关闭；不记住最小化或隐藏状态。恢复时依据显示器工作区与 DPI 调整，断开副屏后回到可见区域。窗口记录采用独立文件和后台合并写入，不影响项目存档。开发时若正式程序仍在运行，同标识的启动会唤回正式程序；需要并行验收时使用 QA 标识。

应用内更新提供启动后检查开关、关于页手动检查、更新说明、下载进度/取消/重试与安装前保存保护。正式公钥暂未配置，当前构建显示“更新服务尚未配置”，不会自动下载安装；签名发布流程和首次上线说明见 [UPDATES.md](UPDATES.md)。

## 本地运行

开发和测试使用 Node.js 24、npm。

```sh
npm ci
npm run dev
```

默认访问 http://localhost:3000 。浏览器数据按协议、主机和端口隔离，请固定使用同一个地址；切换到其他端口不会看到原来的本地项目。

```sh
npm test
npm run lint:core
npm run build
npm run preview
```

生产构建位于 `dist/`，通过静态 Web 服务部署。`npm run dev` 仅用于开发；实际交付前仍需在目标浏览器验证导出和项目容量。

发布与升级要求、资源缓存规则和分包故障演练见 [DEPLOYMENT.md](DEPLOYMENT.md)。资源加载失败时保留当前编辑区，提供已同步内容备份与手动重新加载入口，不自动刷新页面。

## 常用操作

- 从步骤列表添加、粘贴或拖入图片；搜索步骤名称/说明，筛选缺说明或未标注步骤。筛选时暂不排序。
- 左侧选择工具，顶部设置参数；文字点击创建，气泡拖动创建，双击已有文字标注重新编辑。
- Shift 点击画布或对象列表进行多选，Ctrl+A 选择可编辑对象；拖动和方向键可批量移动，Shift+方向键移动 10px。
- Ctrl+D 批量复制，Delete 删除；Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做。输入文字时保留文本快捷键。
- 展开右侧“标注对象”可锁定/解锁及显示/隐藏。锁定对象保留在导出中，隐藏对象不参与导出；隐藏序号不计入连续编号。
- 文字编辑中 Enter 换行，Ctrl+Enter 提交，Esc 取消。结束编辑后才将文本草稿写入项目。

步骤说明的富文本编辑器在项目内复用；切页会隔离本页的文本撤销历史，Ctrl+Z 不会把上一页说明带入当前页。离开文本输入区后，可使用工作台撤销恢复项目级修改。

切页、复制/删除步骤、切换项目和下载项目备份前，会收尾当前文字编辑。组合输入期间等待输入结束及编辑器更新，再使用最新状态；若输入法未发出结束事件，会保留当前页面并提示确认候选文字后重试。画布文字/气泡在组合输入期间不响应 Esc 或 Ctrl+Enter，失焦也会等待组合输入结束再提交。

## 项目保存与恢复

桌面支持 Ctrl+O 打开 JSON、Ctrl+S 保存、Ctrl+Shift+S 另存为，显示关联文件名与待保存状态。“本机自动保存”和“保存到 JSON 文件”分别管理；文件关联只在当前会话内有效，重启需重新选择授权。项目菜单提供最近本地项目及不改变关联的独立备份。外部修改冲突时可另存为保留当前内容。Web 的 Ctrl+S 继续下载项目 JSON。

Web 通过 IndexedDB、桌面通过应用本地 SQLite 自动保存项目。顶部显示待保存、保存中、成功或失败；失败提示可点击重试。

“项目 → 本地项目与历史版本”可重新打开项目，或恢复最近 3 个不同版本。新建/切换前会保存当前工作区；多个页面发生冲突时阻止旧内容覆盖，并在切换时尝试保存冲突副本。

Web 项目列表显示网站存储占用估算，桌面不使用浏览器配额估算数据库容量。可删除非当前项目；删除前需确认，会永久清理该项目和历史版本，只回收不再被其他存档引用的图片，请先备份。保存失败时仍可打开列表清理空间；切换项目仍需先保存成功。

编辑器渲染异常时显示恢复页面，可下载最后一次同步到项目状态的 JSON，再重新加载。本地存档不会被自动清除；未提交的文字草稿、进行中的手势以及异步事件错误不在此恢复保证内。

请定期下载 JSON 项目备份。清除网站数据、浏览器隐私模式或更换浏览器后，本地记录可能不可用。JSON 备份内嵌图片，可跨电脑导入；导入文件会创建独立本地项目。

存储故障时，点击保存状态或“项目 → 本地存储与恢复”查看原因、重试、备份当前编辑内容或导出旧存档恢复包；桌面端还可定位数据目录。旧存档包保留原始数据和逐条失败报告，可能是迁移前版本。桌面真实验收结果与待验收流程见 [DESKTOP_ACCEPTANCE.md](DESKTOP_ACCEPTANCE.md)。

图片独立去重存储。导入最多同时处理两张，单图上限为 4000 万像素；该限制不代表项目总体容量保证，长项目需要结合本机内存验证。

自动保存复用未变化图片的哈希，仅写入缺失图片，修改步骤说明不会反复重写全项目截图。资源清理只遍历图片键；项目状态和 JSON 备份仍使用内嵌图片，尚未提供项目总内存上限保证。

预览逐页生成并显示进度，可取消后重试。关闭预览或切换格式会清理旧任务和图片 URL。导出也支持进度与取消；当前页栅格化或文档打包结束后才会响应取消，已经开始的浏览器下载无法撤回。

“设置 → 文档排版”统一配置当前项目的步骤布局、文档头部、字号、对齐和页脚，提供预览入口。支持上文下图、左文右图、左图右文、双列、三列及双图共享说明区；按原步骤顺序连续分行，末行保持列宽。同一行以最高说明区统一留白，所有截图顶部对齐。共享说明区依次展示该组原有说明，不合并原始截图或改变画布标注序号。左右布局可选择文字占宽 30%、40% 或 50%。当前版式应用于整篇项目，暂不提供单独步骤的分组和覆盖。

导出预览右上角的“版式设置”可展开/收起侧栏，直接修改步骤布局、头部和文字页脚；与设置中心共用控件，修改会随项目保存并参与撤销。连续输入/拖动后约 300ms 更新预览，生成期间保留上次成功的画面并显示状态。步骤编号支持常规文字、圆点数字加步骤名称、文字加 Badge，装饰编号可选颜色。头部高度支持 80–600px，内容较多时自动撑开；主标题与副标题使用明确行高和留白，避免裁切。

文档头部支持副标题、纯色/图片背景、文字颜色、背景铺满/完整显示、暗色遮罩和 Logo。背景与 Logo 在本机压缩处理并随项目保存；支持 PNG/JPEG/WebP/GIF（动图取静态帧），输入不超过 20 MiB、4000 万像素。背景最长边缩至 1600px，Logo 缩至 512px，单项处理后不超过 4 MiB。旧项目沿用原单列版式。长图/PDF 共用预览排版；Word 用无边框表格组织图文，带背景或 Logo 的头部以图片输出，正文说明仍可编辑。Word/WPS 实际分页以对应软件为准；超高行在 PDF 中可能跨页切分。单张/批量纯标注图片导出不添加文档头部和步骤说明。

“导出 → 导出标注图片…”支持当前、指定多张和全部图片；单张输出 PNG，多张输出 ZIP。右侧每张图片的下载按钮可直接导出，不切换当前画布。只输出当前裁剪结果和可见标注，保留画布序号，不添加标题、步骤说明和页脚。文件以项目原顺序编号，重名也不会互相覆盖。每批最多 1000 张、PNG 合计 200 MiB；超限请分批选择。隐藏打码/遮挡会单独提示，缺少步骤说明不阻止纯图片导出。

长图较短时下载一个 PNG；需要分片时下载一个 ZIP，内含按顺序编号的 PNG，避免浏览器拦截连续下载。PDF 的单个步骤先移至新页，必要时按剩余高度等比缩放截图；超长说明仍会跨页。

## AI 辅助

可配置兼容接口生成说明、建议标注和隐私检查，也可使用演示模式。真实调用会向所配置服务发送处理后的截图；已有隐私遮挡会在发送前应用，包括界面中隐藏的遮挡对象。自动检查不能保证发现全部敏感信息。

新配置默认仅在当前标签页会话保存 API Key，刷新保留；可选择“在此设备记住 API Key”以持久保存。切换到会话模式会移除旧的持久密钥。已有配置保持原先的设备保存模式，需主动调整。两种模式都不是加密保险箱，浏览器会话恢复可能保留会话数据；请使用受信任设备。

## 开发维护

工具入口见 `src/lib/tools/catalog.ts`，几何规则见 `annotation-geometry.ts`，新增工具步骤与实施边界见 [STABILITY.md](STABILITY.md)。

CI 执行全项目 ESLint、依赖安全审计、回归测试与生产构建。当前测试以数据、几何和渲染调用为主，尚不能替代跨浏览器视觉和大量图片压力测试。

Word、PDF、文档栅格排版及 AI 分别按需加载，AI 面板首次打开时加载，之后切换标签保留任务与配置状态。首次使用相关功能需要获取对应脚本；导出失败可重试，AI 面板加载失败显示重试入口。静态部署请完整发布 `dist/`，保留旧版本哈希资源以支持更新前已打开的页面。

`npm run check:bundle` 在构建后检查首屏静态依赖链，要求 JavaScript 总计不超过 1.25 MB、gzip 不超过 400 KB，并阻止导出/AI 引擎回到首屏。CI 已接入该检查；这衡量脚本体积，不代表实际首屏耗时或内存峰值。

性能排查：先生成合成项目，再用 `node tests/benchmark-storage.mjs <项目JSON>` 检查隔离存储操作量；浏览器开发服务的 `/tests/performance.html` 可测输入至两帧回调的间隔、长任务和 JS 堆采样。请在独立端口测试，避免修改常用地址中的项目；指标定义和实测边界见 STABILITY.md。

诊断页还会显示 React 渲染、图片载入、底图绘制和适配布局的分段统计；生产页面不启用这些探针。标注对象列表只在展开时创建行控件，折叠时保留对象总数。

输入边界复现：在专用端口启动开发服务并打开 `/tests/input.html`，点击运行组合输入场景。该页生成并重置两个 `qa-input-*` 合成项目，重放浏览器 composition/input/key 事件并检查真实项目存档；请勿在日常使用的地址运行。模拟事件不等于操作系统中文输入法候选窗验收，真实 IME 仍需人工检查。

AI 单页、批量生成和隐私扫描均可取消；批量任务保留已完成结果，支持只重试失败与未完成页。模型返回值会检查结构、长度、数组数量和有限数值，矩形会裁到图内，无效结果不会应用。

开发依赖暂对 `@typescript-eslint/typescript-estree` 的 `minimatch` 定向使用 11.0.8，以修复其默认依赖链的已知漏洞。当前 Node 24 下全量 ESLint 已验证；上游修复后可移除此覆盖并重新审计。
